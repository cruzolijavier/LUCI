# LUCI program request: TS-tools

TS-tools is an automated TS search localization package that uses the GNF2-xTB and DFT methods to automatically find reaction energy paths.

**Docs:** https://github.com/chimie-paristech-CTM/TS-tools

## Installation

```
conda env create -f environment.yml
conda activate ts-tools
pip install .
```

Also needed: Additionally, Gaussian16, xTB and CREST need to be available. The 'xtb_external_script/xtb_external.py' should be set as executable: chmod +x xtb_external_script/xtb_external.py. Finally, the path to the xTB executable, used in 'xtb_external_script/xtb_external.py', needs to be set through the environment variable XTB_PATH, e.g., export XTB_PATH=/path/to/xtb

## Flags

| Flag | What it does | Default | Example / options |
|---|---|---|---|
| --input-file | Input file to consider | None | data/reactions_am.txt |
| --xtb_external_path | Path to the xtb_external.py script | xtb_external_script/xtb_external.py | xtb_external_script/xtb_external.py |
| --reactive-complex-factors-intra | Specifies a list of floating-point numbers representing reactive complex factors for intra-molecular interactions. | [0, 1.2, 1.3, 1.8] | - |
| --reactive-complex-factors-inter | Specifies a list of floating-point numbers representing reactive complex factors for inter-molecular interactions. | [2.5, 1.8, 1.5, 1.3] | - |
| --solvent | Specifies the name of the solvent (needs to be supported in xTB) | None | 'water' |
| --freq-cut-off | Specifies the imaginary frequency cut-off used during filtering of plausible starting points for transition state guess optimization. | 50 | - |
| --target-dir | Specifies the working directory in which all files will be saved | work_dir | - |

## Input

The input file should be a text file, with the extension .txt, containing the mapped reaction SMILES the user whant to run, with an index.
For example: 
R1  [H:2][C:1]([H:3])([H:4])[Cl:5].[Br-:6] >> [H:2][C:1]([H:3])([H:4])[Br:6].[Cl-:5]

## Output

The program return a *out file containing the different steps of the program. At the end, it prints a list of the successfull reaction.
A work_dir and final_work_dir containing one subdirectory for each reaction run, and containing the final geometry of the TS found along with the IRC, and the geometry of the points it connects.
