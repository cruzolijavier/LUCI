# LUCI program request: GoodVibes

Computes thermochemistry (ZPE, H, T.S, G) from quantum chemistry frequency calculations, with quasi-harmonic corrections for low-frequency modes (Grimme / Truhlar entropy, Head-Gordon enthalpy). Also handles temperature and concentration changes, single-point energy corrections, Boltzmann populations, stereoselectivity and reaction-profile (PES) tables.

**Docs:** https://goodvibespy.readthedocs.io/en/latest/

## Installation

```
pip install "goodvibes[full]"
```

Also needed: Python 3.9 or newer (3.10 or newer from the next release). Plain "pip install goodvibes" is enough for the core tables; the [full] extra adds pandas and pyarrow (--csv, --parquet), matplotlib (--pes-plot, --strip-plot), pyyaml (--pes and --selectivity YAML files) and ase. No QM program is needed: GoodVibes only reads their output files. Also on conda-forge: conda install -c conda-forge goodvibes

## Input

The main input has no flag: output files are given as positional arguments, and any number can be passed at once.

<files>   one or more QM output files from a frequency calculation, e.g. ts1.log or conformers/*.log (wildcards are expanded). Accepted extensions: .log and .out (Gaussian 09/16, ORCA 5/6, NWChem, Q-Chem 6, xTB; the program is detected from the file contents) and .extxyz (ASE extended XYZ carrying energy and frequency data, e.g. from MLIP workflows). Other extensions must be registered with --custom_ext. Each file must contain frequencies, otherwise no thermochemistry is printed for it.

--spc     not a file but a suffix. With --spc TZ, every ts1.log is paired with a single-point file ts1_TZ.log (or .out) in the same folder, so the names must share the same root. With --spc link, the single point is read from a later link job inside the same file.

--pes     a YAML text file describing a reaction pathway. Three top-level keys: 'pathways' (name -> ordered list of points, each a species or a sum such as "cat + subs" or "2*A + B"), 'species' (name -> {files: "glob pattern"} matching the output files passed on the command line) and optional 'format' (units, decimals). The output files themselves must still be passed as positional arguments.

--selectivity   a YAML file with a top-level 'labels' key (species name -> filename pattern) or 'files' key (species name -> list of files). For two or three species, repeating --label NAME=PATTERN on the command line does the same without a file.

--import  a JSON file previously written by --json / --export, used instead of re-parsing the output files.

## Output

Always: a table printed to the terminal (one row per structure: E, ZPE, H, T.S, T.qh-S, G(T), qh-G(T), in Hartree) and the same text written to GoodVibes_output.dat in the current working directory (the 'output' part of the name is set by --output).

On request:
--json PATH     JSON with the run options and, per file, the parsed data and thermochemistry (best format for a platform to read back)
--csv PATH      CSV, one row per structure (file, name, scf_energy, sp_energy, zpe, enthalpy, qh_enthalpy, entropy, qh_entropy, gibbs_free_energy, qh_gibbs_free_energy, point_group, level_of_theory, program ...)
--parquet PATH  same columns as the CSV, as Parquet
--xyz           GoodVibes_output.xyz with the optimized Cartesian coordinates of every structure
--pes-plot PATH and --strip-plot PATH   figures, format chosen by the extension (.png, .pdf or .svg)

With --boltz, --label / --selectivity or --pes, extra tables (populations, selectivity ratio and ddG, relative energies in kcal/mol) are added to the terminal output, the .dat file and the JSON.

## Notes

Typical runs:
goodvibes *.log -q -c 1.0 --json results.json
goodvibes *.log -q --temp 353.15 -c 1.0 --spc TZ --csv results.csv
goodvibes TS_*.log -q --boltz --label R='*_R*' --label S='*_S*'
goodvibes *.log -q -c 1.0 --pes pathway.yaml --pes-plot profile.png
(python -m goodvibes works the same as the goodvibes command.)

Things to know:
- Without -q the entropy is still quasi-harmonic (Grimme, 100 cm-1) but the enthalpy is plain RRHO; -q switches both on and is what most users want. Both the harmonic and quasi-harmonic values are always printed side by side.
- Switches (-q, --qh, --symm, --dedup, --check, --imag, --xyz, --nogconf, --lowest-only) take no value. --boltz, --sort and --invert work with or without a value.
- -f sets both cut-offs; --fs and --fh override it for entropy or enthalpy only.
- If -v is not given, scaling factors are looked up from the level of theory found in the files (Truhlar database) and fall back to 1.0. Use -v 1.0 to switch scaling off.
- --ti replaces --temp and prints one row per temperature.
- --pes-plot needs --pes; --strip-plot needs --label or --selectivity; --nogconf and --lowest-only only affect --pes tables.
- All files in one run should share the same level of theory and solvation model; --check verifies this.
- --ee, --cache-save and --cache-read still work but are deprecated (use --label, --export, --import).
- The next release (in the GitHub master branch, not yet on PyPI) adds --si (Supporting Information tables), --profile and the goodvibes-profile command (reaction-profile documents), and --strict-spc. They are left out of the table because pip does not install them yet.
